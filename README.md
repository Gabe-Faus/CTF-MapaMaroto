🪄 Sobre o desafio

Durante suas aventuras em Hogwarts, Harry Potter encontra um objeto que pertenceu a seu pai: o lendário Mapa do Maroto.

Muito mais do que um simples mapa, ele revela passagens secretas, cômodos escondidos e os passos de todos que percorrem os corredores do castelo.

Criado por um grupo de amigos que adorava explorar Hogwarts e se envolver em confusões, o mapa guarda segredos que poucos conseguem desvendar.

Neste CTF (Capture The Flag), você terá a oportunidade de seguir os passos de Aluado, Rabicho, Almofadinhas e Pontas, explorando os caminhos secretos deixados pelos antigos marotos.

Prepare-se para investigar, explorar e colocar suas habilidades à prova. Afinal, para se tornar um verdadeiro maroto, não basta conhecer o mapa: é preciso saber desvendar seus segredos!

⚙️ Como executar o ambiente

Para iniciar a máquina do CTF, siga os passos abaixo:

1. Clone e acesse o diretório
bash
mkdir ctf-mapamaroto && cd ctf-mapamaroto

2. Baixe o arquivo de configuração
bash
curl -sSL https://raw.githubusercontent.com/Gabe-Faus/CTF-MapaMaroto/main/deploy/docker-compose.yml -o docker-compose.yml

3. Inicie o ambiente
bash
docker compose up -d


Pronto! O ambiente estará em execução.
